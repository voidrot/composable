# mailpit

Mailpit is a multi-platform email testing tool for developers

## Variables

The following environment variables can be configured:

| Variable | Default Value | Description |
|----------|---------------|-------------|
| `MAILPIT_VERSION` | `v1.29` | | 
| `MAILPIT_HTTP_PORT` | `8025` | | 
| `MAILPIT_SMTP_PORT` | `1025` | | 
| `MAILPIT_MAX_MESSAGES` | `500` | | 
| `MAILPIT_DATABASE` | `` | | 
| `MP_ALLOW_INTERNAL_HTTP_REQUESTS` | `true` | | 
| `MP_DISABLE_HTTP_COMPRESSION` | `true` | | 
| `MP_SEND_API_AUTH_ACCEPT_ANY` | `true` | | 
| `MP_SMTP_DISABLE_RDNS` | `true` | | 
| `MP_WEBHOOK_URL` | `` | |
